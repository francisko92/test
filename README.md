# Vikings Verds · verificació de socis

Web pública de verificació dels carnets digitals de l'Associacio Esportiva Almenar Futsal.

- Verificació directa: `?id=VV-001`
- Font pública d'estat: `members.json`
- No publica DNI, telèfon, correu, adreça ni dades bancàries.
- El workflow `.github/workflows/pages.yml` publica automàticament a GitHub Pages quan Pages està configurat amb **Source: GitHub Actions**.
